# Security Policy

## Supported Versions

| Version | Supported          |
| ------- | ------------------ |
| 3.0.x   | :white_check_mark: |
| < 3.0   | :x:                |

Earlier major versions will be considered if they are important due to other
releases.

## Reporting a Vulnerability

Please report vulnerabilities to [OCaml Security Response Team][SRT]
according to their policy.

[SRT]: https://ocaml.org/security
